# Product Sales Analysis System

商品销售数据全面分析系统

## 功能特性

- 销量排名分析（TOP10、中位数、滞销品）
- 热销原因深度拆解
- 6类核心可视化图表
- Excel报告导出

## 文件说明

- `product_sales_analysis.py` - 原始版本
- `product_sales_analysis_v2.py` - 优化版本（面向对象设计）
- `product_sales_analysis.png` - 可视化图表
- `sales_analysis_report.xlsx` - Excel分析报告

## 技术栈

- Python 3.x
- Pandas / NumPy
- Matplotlib / Seaborn
- OpenPyXL
